API REST de Inventário TCG
Este projeto é uma API REST desenvolvida para gerenciar o inventário de um catálogo de Trading Card Games (TCG).
O sistema foi criado para facilitar o controle de acervo, permitindo o cadastro detalhado de cartas avulsas (singles), organização por expansões, precificação e monitoramento de estoque.

Para testar o CRUD completo, rode o projeto localmente e acesse:

http://localhost:3000/api-docs

Como rodar o projeto
1. Clone o repositório
2. Instale as dependências com `npm install`
3. Inicie o servidor com `npm run dev`
4. Para rodar os testes, utilize `npm test`
